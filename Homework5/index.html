Welford's Recurrence and Sampling Variability

Online computation of sample statistics and an experimental study of penetration scores across independent attackers.

01Welford's recurrence formulas

Let x₁, …, xₙ be observations, Mₙ their mean, and SSₙ = Σᵢ₌₁ⁿ(xᵢ − Mₙ)² the sum of squared deviations. Start with M₀ = 0 and SS₀ = 0. Following Knuth's incremental mean update, set δₙ = xₙ − Mₙ₋₁:

Mₙ = Mₙ₋₁ + δₙ / n

For the first n − 1 observations, write xᵢ − Mₙ = (xᵢ − Mₙ₋₁) − δₙ/n. When we square and sum, the cross term vanishes because Σᵢ₌₁ⁿ⁻¹(xᵢ − Mₙ₋₁) = 0. These observations therefore contribute SSₙ₋₁ + (n−1)δₙ²/n². The new observation contributes (xₙ − Mₙ)² = (n−1)²δₙ²/n². Adding both parts yields:

SSₙ = SSₙ₋₁ + (n − 1)δₙ² / n
= SSₙ₋₁ + δₙ(xₙ − Mₙ)

The unbiased sample variance uses the denominator n − 1:

s²ₙ = SSₙ / (n − 1), for n ≥ 2

Equivalently, s²ₙ = [(n − 2)s²ₙ₋₁ + (n − 1)δₙ²/n] / (n − 1) for n ≥ 3. The first variance is defined at n = 2.

Three-line core implementation

const delta = x - mean;
mean += delta / count;
SS += delta * (x - mean);

Initialize mean = 0 and SS = 0; increment count before these three lines. After n observations, sample variance = SS / (n − 1). The recurrence avoids storing all observations.

02Score distribution and theoretical values

Each of m independent hackers attempts to penetrate n systems. Each attempt receives an independent integer score X uniformly drawn from 0 through 10, with P(X = k) = 1/11 for every k ∈ {0, …, 10}. The score is a simplified statistical model, not a real-world security prediction.

Theoretical meanμ = E[X] = (0 + ··· + 10) / 11 = 5All eleven scores have equal probability.
Theoretical varianceσ² = E[(X − 5)²] = 10Equivalently E[X²] = 35, so σ² = 35 − 25 = 10.

For each hacker, Welford's algorithm produces a sample mean and unbiased sample variance. Across all m hackers, we average those statistics and compare them with μ and σ².

05Statistical interpretation

Unbiased estimation: For independent identically distributed scores, E[X̄] = μ = 5 and E[s²] = σ² = 10. Therefore the average of m sample means and the average of m unbiased sample variances should fluctuate around 5 and 10, respectively, rather than being exactly equal in any single experiment.

Increasing n: Var(X̄) = σ²/n = 10/n, so sample means become more concentrated around 5 as each hacker attempts more systems. Sample variances also become more stable as n increases, although their variability does not follow the same 10/n formula.

Increasing m: More independent hackers make the averages across hackers more reliable, but do not change the sampling variability of one hacker's statistics at fixed n.

Inferential statistics: Unbiasedness explains why these estimators target the population parameters; shrinking sampling variability explains why larger samples generally produce more precise estimates. These principles underpin standard errors, confidence intervals and hypothesis tests.

Conclusion Welford's recurrences provide numerically stable, memory-efficient sample statistics. Across many hackers the averages approach their theoretical targets, and increasing the number of systems reduces the spread of the individual estimates.
